Send all at once from Outlook

Works in classic Outlook for Windows (the desktop app). One-time setup takes about two minutes.

One-time setup

  1. Download BulkMailer.bas
  2. In Outlook press Alt+F11 → File ▸ Import File… → pick BulkMailer.bas.
  3. Close the editor. If macros are blocked: File ▸ Options ▸ Trust Center ▸ Trust Center Settings ▸ Macro Settings → Notifications for all macros, then restart Outlook.

Every event

  1. Generate certificates (or the voucher mail kit) here — the ZIP has the files plus mail-list.csv.
  2. Extract the ZIP to a folder (right-click ▸ Extract All).
  3. In Outlook press Alt+F8 → run SendBulkMail → pick that folder.
  4. Choose Drafts first to check a few, then run again with Send now — or send straight away.

Each person gets their own email with their own attachment. A send-log.csv is written to the folder so you can see who was sent what. The macro pauses briefly between emails so Exchange doesn't throttle you.

No macros allowed / using new Outlook?
  • Vouchers: Word mail merge works without macros — open the Word doc ▸ Mailings ▸ Start Mail Merge ▸ E-mail Messages, select mail-list.csv as recipients, insert fields, Finish & Merge ▸ Send Email Messages. Voucher details go in the email body.
  • Certificates (attachments): use Power Automate — upload the folder to OneDrive, put mail-list.csv in an Excel table, and use “Apply to each” → “Get file content” → “Send an email (V2)” with the attachment. See docs/OUTLOOK-GUIDE.md in the repo.
