What is mail merge?

Mail merge joins one template with a list of people to make a personal copy for everyone — 200 rows in, 200 finished certificates or emails out, each with the right name and details.

📄 Template+📋 List→✉️ One copy each

This app does the making (certificates, voucher pages, email text). Power Automate — part of your Microsoft 365 login — does the sending from your own Outlook mailbox. Works with new Outlook, no macros.

Email text

Filled in for every person when you download a ZIP. Placeholders: {Name} {Event}; vouchers also {Brand} {RefID} {Pin} {Expiry} {Amount}.

Send with Power Automate

1Generate here → ZIP contains a Mail Merge folder (files + mail-list.xlsx)
2Upload that folder to your OneDrive
3Click Run on your flow — everyone gets their own email & attachment

One-time setup · about 10 minutes

  1. Make a first ZIP: turn on 🧪 Test mode (left), generate certificates for a couple of names, extract the ZIP and drag the Mail Merge folder into OneDrive ▸ My files. The flow needs the file to exist while you build it.
  2. Open make.powerautomate.com and sign in with your Hexaware account.
  3. + Create ▸ Instant cloud flow. Name it Mail Merge - Send, pick Manually trigger a flow, click Create.
  4. Click + under the trigger ▸ search List rows present in a table (Excel Online (Business)):
    • Location: OneDrive for Business · Document Library: OneDrive
    • File: click the folder icon ▸ Mail Merge ▸ mail-list.xlsx
    • Table: MailList
    • Settings tab ▸ Pagination on ▸ Threshold 5000 (otherwise it stops at 256 people)
  5. Click + ▸ search Get file content using path (OneDrive for Business). In File Path type /Mail Merge/ then insert dynamic content File (⚡ icon). Power Automate wraps it in a For each automatically — that's correct.
  6. Inside For each, click + ▸ Send an email (V2) (Office 365 Outlook):
    • To: Email · Subject: Subject · Body: Body (all dynamic content)
    • Advanced parameters ▸ Attachments: Name = FileName, Content = File Content
    • Advanced parameters ▸ CC: Cc
  7. Still inside For each, click + ▸ Delay ▸ Count 2, Unit Second (keeps you under Outlook's sending limit).
  8. Save ▸ Test ▸ Manually ▸ Run flow. Allow the connections if asked. Check your inbox for the 3 [TEST] emails. ✅ Setup done — you never edit the flow again.

Every event · about 2 minutes

  1. Untick 🧪 Test mode. Generate certificates (or the voucher mail kit) and extract the ZIP.
  2. Drag the new Mail Merge folder into OneDrive ▸ My files and choose Replace when asked. (Don't delete the folder first — the flow is linked to that file.)
  3. Power Automate ▸ My flows ▸ Mail Merge - Send ▸ Run. Done — watch the run history for any ❌.
Something went wrong?
  • "File not found" on Get file content — the file must be inside Mail Merge directly, not a sub-folder. Upload the folder from the ZIP as-is.
  • Old people got emailed again — the flow sends to everyone in mail-list.xlsx; make sure you replaced it with the new one.
  • "Excel file not found" — you deleted and re-uploaded the folder. Open the flow, pick the file again in step 4, save.
  • Sending from a team mailbox — use Send an email from a shared mailbox (V2) instead of step 6 (you need Send-As rights).
  • Power Automate won't open — your account may not have it enabled; ask IT for Power Automate (it's in Microsoft 365 E3/E5).
